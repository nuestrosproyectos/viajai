# Avatares que hablan para el canal de YouTube (estudio 17-11-2026, 5 agentes)

Formato base: vídeo de 12–15 min con ~4 min de avatar a cámara (inicio, final y cortes) y el resto cartas + voz en off.
Coste por vídeo de 15 min con ese formato (precios de páginas oficiales salvo donde se indica):

| Opción | Coste por vídeo | Notas |
|---|---|---|
| MuseTalk sobre plano base (GPU alquilada) | céntimos | Solo mueve la boca; gestos repetidos |
| InfiniteTalk en GPU alquilada (Vast.ai/RunPod) | ~0,7–1,7 $ | Muy buena calidad; 1–2 días de montaje técnico; velocidades sin verificar |
| HeyGen Creator 29 $/mes, Avatar III foto (7 cr/min) | ~1,4 $ | ~21 vídeos/mes |
| HeyGen Creator 29 $/mes, Avatar IV foto (16 cr/min) | ~3,2 $ | ~9 vídeos/mes; API: 2,31 $/min |
| D-ID API | ~2,8 $ | Menos realista |
| Hedra Character-3 API 540p (1,5 $/min) | ~6 $ | Muy buen talking head |
| Kling AI Avatar v2 en fal.ai (0,056 $/s) | ~13,5 $ | |

YouTube: marcar «contenido alterado o sintético»; evitar contenido repetitivo («inauthentic content», julio 2025). YPP: 1.000 subs + 4.000 h. RPM estimado del nicho: 0,5–2 € (sin datos oficiales).
